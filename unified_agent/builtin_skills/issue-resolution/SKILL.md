# Issue resolution

- Prefer existing tests, logs, stack traces, and focused inspection as evidence.
- Reproduce only if it reduces uncertainty; do not create a test merely to satisfy a sequence.
- Make the smallest change consistent with the observed behavior and project conventions.
- Validate the original reported behavior when practical, and state limits honestly.
